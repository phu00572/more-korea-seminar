# 台灣山難事故及高風險環境發生案例與救援方法（韓國線上研討會）

Reveal.js 互動簡報（html-slide-builder），內容 15 頁＋投票頁＋3 個影片頁＋結尾。

## 播放

- **本機預覽**：用瀏覽器開 `index.html`（建議透過本機伺服器，或部署後的網址）
- **線上網址（部署後）**：https://phu00572.github.io/more-korea-seminar/

## 鍵盤快捷鍵

| 按鍵 | 功能 |
|------|------|
| → / ← | 下一頁／上一頁 |
| 空白鍵 | 下一頁；在影片頁是播放／暫停 |
| F | 全螢幕 |
| K | 顯示／隱藏韓文字幕 |
| N | 講稿面板＋計時器（第一次按下開始計時，目標 10:00） |
| T | 計時器歸零 |
| S | Reveal 講者視窗（另開視窗，顯示講稿與下一頁） |

## 聽眾互動（Firebase）

- **投票頁「先猜再看」**（P.04 前）：聽眾掃 QR code 直接進入投票頁；講者按「揭曉答案」標出正解。
- **匿名提問牆**：每一頁左側都可以拉開，聽眾可用韓文提問、互相按讚，讚數高的排前面。
- **課後清空資料**：在網址後面加 `?reset=1`（例如 `https://phu00572.github.io/more-korea-seminar/?reset=1`），確認後就會清空投票與提問牆。

## 影片（YouTube）

打開 `index.html`，在 `<script>` 一開頭的 `YOUTUBE` 設定區貼上連結：

```js
const YOUTUBE = {
  V1: 'https://youtu.be/xxxxxxxxxxx',  // P.02 之後：台灣山林之美
  V2: '',                               // P.04 之後：山域事故救援實況
  V3: ''                                // P.15 之後：結尾影片（不計入 10 分鐘）
};
```

- 支援 `youtu.be/…`、`youtube.com/watch?v=…`，也可以加 `?t=30` 指定從第 30 秒開始播放。
- 切到影片頁時，按空白鍵就能播放或暫停；離開影片頁會自動暫停。
- 如果你點過影片畫面，鍵盤會停在影片裡。這時先點一下影片外的空白處，鍵盤才會回到簡報。
- 影片要在 YouTube 上設為「公開」或「不公開」（不要選「私人」），並且允許嵌入。
